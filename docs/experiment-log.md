# 実験記録

## 2026-10-03 — v1：球殻グリッパー（摘採範囲が大きすぎるため不採用）

以下は旧試作の履歴。ユーザーから「大きな枝ごと刈り取っているのでNG」と指摘された。回収動作の成功を選択摘採の成功とは扱わない。旧生成物・ソース・結果はローカルの `output/cage-v1-rejected.zip` に保存し、現行の `output/cage/` はv2で再生成した。

### 目的・範囲

6枚の球殻で剛体の模擬芽を包み、固定拘束を解除した後、球殻との接触だけで保持・搬送・箱への排出ができるかを確認する。AI認識、実際の茎の破断、柔軟な茶葉、実機は対象外。既知位置へ最初からグリッパーを配置しており、自動接近も未実装。

### 環境・再現手順

- macOS Intel x86_64、Python 3.12.14、CadQuery 2.5.2、MuJoCo 3.2.7。
- リポジトリ内に新規の `.venv` を作り、`requirements.txt` の版を導入して実行。他OSや別PCでのクリーン再現は未検証。
- この環境では導入を試みたMuJoCo 3.14に適合するバイナリが見つからず、3.2.7を使用した。
- `config/cage.json` を入力として、READMEの「標準の生成・検証手順」を実行する。
- 乱数は使用しない。初期位置は下記の固定値。設定のseed=42は将来の乱数試験用で、現在の結果には影響しない。
- CAD単位mm、力学単位m・kg・rad。模擬芽の質量2.2g、重力9.81m/s²、摩擦係数の仮定0.55。
- 球殻は独立した理想位置制御。重力補償を有効にしており、実サーボの性能試験ではない。

### 試験条件と成功判定

初期XYずれ(mm)は `(0,0), (+5,0), (-5,0), (0,+5), (0,-5)` の5種類。

1. 仮想切断ブロックが閉じ、約2.401秒で初期の茎固定拘束を解除する。
2. 3.0〜5.95秒の間、対象の基準点が球中心から水平方向46mm未満、鉛直方向−100〜+45mmにあることを保持の代理指標とする。対象の全形状が球内に入っていることを保証する指標ではない。
3. 10秒時点の対象基準点が箱内（X=130〜270mm、|Y|<65mm、Z=30〜120mm）にあり、モデル全体の一般化速度の絶対最大値が0.01未満であることを収納判定とする。速度成分はm/sとrad/sが混在するため、単一の物理的な速度値としては扱わない。
4. 数値が有限で、MuJoCoの警告がないこと。
5. 球殻を開いたままの対照では保持・収納が失敗すること。切断後に対象を球へ固定する拘束は一切使わない。

通常の時間刻みは1ms。半分の0.5msでも同じ5位置を再計算する。これは成功・失敗の時間刻み感度を見る試験で、連続軌道や接触力の収束を保証しない。

### 修正過程と失敗

- 初案は球殻とベースの取付部に干渉があった。静的CAD検査で46〜58mm³程度の重なりを確認し、ヒンジ周囲の肩を切り欠いた。形状修正前の動作成功は、干渉を含む形状の結果なので最終結果とは扱わない。
- 肩の修正後、底穴約10.45mm・時間刻み2ms・上昇位置のまま1秒で開く案では、5条件中3条件だけが収納できた。Y方向±5mmの条件が失敗した。
- 箱の上で下降し2秒かけて開く案では、同じ底穴・時間刻みで4/5条件が収納できた。Y方向+5mmでは対象が球殻上部付近へ持ち上がり、最後に箱外へ落ちた。
- 茎半径1.8mmと5mmの位置ずれを許容するには、穴半径5.23mmは不足する。底穴を約15.64mmへ拡大し、時間刻みを1msにした。この2変更の効果は個別には切り分けていない。

### CAD検査結果

- 球殻、ベース、切断代用ブロック：有効な単一ソリッド。各STLは閉じた形状で正の体積を持つ。
- 同期して0°, 11°, 22°, 33°, 44°, 55°に開いた6姿勢：隣接球殻およびベースとの重なり体積は各0mm³。
- これは離散姿勢の検査。全角度での連続干渉、非同期、印刷公差、駆動リンク、切断ユニット取付を検証していない。
- 最終形状：球殻1枚約12.03g（完全充填の密度仮定）。外径104mm、厚さ2mm、底穴約15.64mm。衝突判定は球殻1枚につき158個の小さな凸パッチで近似する。

### 動作検査結果

| 条件 | 保持 | 収納 | 計算警告 |
|---|---|---|---|
| 最終形状・1ms、固定5位置 | 5/5 | 5/5 | 0 |
| 最終形状・0.5ms、同じ5位置 | 5/5 | 5/5 | 0 |
| 開放したままの失敗対照、1ms | 0/1 | 0/1 | 0 |

10秒の計算1条件あたり、今回の実測所要時間は通常刻み約2.1〜3.6秒、半分の刻み約3.9〜4.2秒。通常位置の動画生成は約7.6秒。他処理と並行していたため性能指標には用いない。

時間刻みを変えると箱内の最終位置が数cm変わる条件がある。収納判定は一致したが、細かな接触軌道・力の予測精度は検証できていない。また、設計を調整した同じ5条件での再試験なので、独立した評価データや実物の収穫成功率ではない。

旧版の機械可読結果は保存Zip内の `test-report.json`、通常位置の結果は `run-report.json`。動画は通常位置1条件の10秒デモであり、最終課題用の1〜5分動画ではない。

### 次に必要な実験

- 葉の大きさ、姿勢、質量、摩擦、柔軟性を変える。底穴拡大による小さい対象のすり抜けを確認する。
- 6枚を同期させる実機構と切断ユニットの取付設計。仮想切断ブロックは現在、取付のない位置表示である。
- 1枚を試し刷りしてヒンジの嵌合・可動域を確認する。104mm径のヘッドを高さ150mmの模型へ収められるか再検討する。
- AI検出と位置合わせを接続する。現状の試験を最終課題のAI性能として報告しない。

## 2026-10-03 — v2：母枝と古葉を残し、先端の一芯二葉だけを回収

### 変更と仮定

- 摘む物体は芽1個・若葉2枚・短い茎だけ。茎の中心線は28mm、芽の先端から切断面までは約35mm、質量0.5g。これらは設計上の仮定で、写真の実測値ではない。
- 母枝・支持枝・古葉3枚・隣の芽を独立した固定接触対象にした。これらを切断・解放する処理はない。
- 球殻を60%へ縮小：外径62.4mm、厚さ1.2mm、底穴約9.39mm。球殻1枚約2.60g、6枚とベースで約20.1g（密度仮定、駆動部除外）。ヒンジ穴は1.92mmになり、実部品向けの造形公差は未設計。
- 切断点Z=147mm、球中心Z=180mm。長い母枝を切るのでなく、若葉2枚の下の細い茎に相当する接続だけを解除する。
- 母枝などと球殻・切断代用ブロックの接触を毎ステップ調べ、切断前に接触すれば開いて中止する。これは接触後の中止であり、接触自体や実物の損傷を防ぐ保証ではない。
- 位置・切断点は既知。XYずれ2.5mm超は事前に中止する。AIやセンサーによる自動選択ではない。

### 条件・判定

v1と同じ環境とREADMEの生成手順。中央とXY各±2mmの5位置、通常1msおよび半分の0.5msで試験する。v1の±5mmより狭い条件であり、性能向上として直接比較しない。

保持は解除後の3〜5.95秒で対象基準点が球中心から水平28mm未満、鉛直−40〜+30mmの範囲内。対象全体の包摂を保証する指標ではない。箱内位置・停止の判定はv1と同じ。これに「残す植物への接触ステップ数0」「中止なし」「解除した物体が短い芽だけ」を加える。

### 結果

| 試験 | 結果 |
|---|---|
| 通常1ms、中央・XY各±2mm | 5/5で先端を保持・回収。残す植物への接触0 |
| 半分の0.5ms、同じ5位置 | 5/5で先端を保持・回収。残す植物への接触0 |
| 球殻を開いたまま | 先端が落下、保持・回収は失敗（対照として期待通り） |
| 古葉を球殻の閉じる範囲へ配置 | 古葉との接触を4ステップ検出し中止。切断・回収なし |
| 既知の位置ずれ+5mm | 切断前に中止。切断・回収なし |
| CAD・STL | 3部品とも有効な閉じた形状。6開き角で隣接球殻・ベースの重なり0 |

全動作試験でMuJoCo警告なし、数値は有限。通常条件の計算は10秒の動作を約2秒程度で実行（並行処理あり、性能測定ではない）。細かな最終位置は時間刻みにより変わり、接触力・軌道の収束は未検証。

### 検査中に修正した問題

古葉の侵入対照を最初に作った際、コンパイル済みモデルの静的な形状位置だけを変更したため、接触探索の内部データが更新されず、接触が検出されなかった。植物の配置をXMLに設定してからモデルを作り直すよう変更し、対照で中止することを再確認した。通常5位置・時間刻み半減・全対照も再実行した。

### 限界

これは既知配置の剛体モデルでの、回収範囲を修正したデモである。残す植物は固定され、変形・損傷・誤切断の破壊モデルはない。実写からの一芯二葉検出、隠れた古葉、植物密集時の接近、実切断、印刷強度、実機の安全性は未検証。「実物の茶樹を傷付けず選択摘採できる」とは結論しない。

## 2026-10-03 — v3：肩・肘の2関節アーム

### 変更と仮定

- X/Z直動2軸を撤去し、肩・肘の2回転関節を追加。リンク長各220mm、固定手首、XZ平面内のみの動作。球殻開閉6軸・切断代用2軸はアームの関節数に含めない。
- 関節角は目標位置から逆運動学で求め、位置制御に渡す。球中心を直接移動させたり、姿勢を保持する隠れた手首軸を使ったりしていない。
- 手首固定のため、今回の軌道では球殻が最大約26°傾く。保持判定を球のローカル座標に変更した。
- 関節角制限内、および球中心の最大追従誤差10mm未満を合格条件へ追加。模擬芽・固定植物・位置ずれ条件はv2を維持。
- 理想重力補償、トルク上限±6N·mなどはシミュレーション用仮定。実機のサーボ選定結果ではない。

### 不具合と修正

最初のモデルでは肩の取付部と固定台が衝突物として扱われ、肩に大きな摩擦拘束が発生した。回収自体はできたが、先端が目標から最大約202〜209mm外れ、追従基準で不合格だった。制御ゲイン調整だけでは解消しなかったため、接触と関節力を調査し原因を確認した。

関節取付部の固定台と上腕、および上腕と前腕を接触対象から除外。植物との接触監視は維持した。これは関節の概念モデルであり、取付部の実際の公差・形状を検証した修正ではない。

最初の薄い葉モデルでは箱の中まで到達したが、10秒および12秒後も回転速度が停止基準を超えた。従来の3方向接触は転がり・ねじれ摩擦を計算していなかったため、葉を6方向接触へ変更し、摩擦 `.55 .0001 .00002` を仮定。観察時間を12秒とした。摩擦は実測値ではなく、成功率を実機性能として扱わない。

## 2026-10-03 — v6：3か所を1枚ずつ巡回

### 実装と合格条件
