# 球殻グリッパー — 葉1枚ずつの回収試作

現行v7は同じ株の複数の対象葉を、毎回1枚＋短い葉柄だけ回収する。3株×各2枚の検証配置で、芽や複数枚を束ねない。v4の天井走行・球殻寸法は維持。内半径15mm、厚さ1mm、外径32mm、底穴約4.69mm、ヒンジ穴0.96mm、球殻1枚約0.542g。各対象の真上で球中心高さ90mm、葉柄の切断代用点高さ73.5mm。搬送・制約は `arm-design.md` を参照。

**以下はv2の設計履歴**。数値は旧版のもので、現行寸法の正本は `config/cage.json` とする。v4でも6枚の中空球殻という形状意図を維持し、小型ハウスに合わせて縮小した。駆動機構・公差は未設計。

## 設計意図

ユーザーの構想は「先端の芽と若葉2枚だけを包み、その下の細い茎を切った後も球内に捕まえる」。大きな枝や古葉ごとの刈り取りはNG。v1の長い回収対象は不採用とし、対象を約35mmの先端に変更した。母枝・古葉3枚・隣の芽を別の固定された接触対象として残す。色は黄緑が摘む部分、濃緑・茶色が残す部分。

寸法は初期検証用の仮定で、実物の枝や新芽の採寸結果ではない。3Dプリント用STLは形状確認用であり、そのまま駆動可能な完成品ではない。

## 初期寸法

| 項目 | 値 |
|---|---|
| 内側の球半径 | 30 mm |
| 球殻厚さ | 1.2 mm |
| 外径 | 62.4 mm |
| 球殻数 | 6 |
| 各球殻の方位角 | 58° |
| 球殻間の隙間 | 2°、赤道付近で約1.05 mm |
| 球の下部開口 | 約9.39 mm |
| ヒンジ穴径 | 1.92 mm（形状縮小値。実ピンに合わせた公差・強度設計は未実施） |
| 最大開き角 | 55° |
| STLの必要個数 | petal ×6、base ×1、cutter_placeholder ×2 |

球殻は完全な密閉容器ではない。茎の通り道、上部、隙間から細い葉が抜ける可能性を実物で確認する必要がある。仮定した密度1.24g/cm³の完全充填時、球殻1枚の推定質量は約2.60g。6枚とベースだけで約20.1gであり、サーボ等を含まない。小型サーボの採用は、必要トルクを測ってから判断する。

v2はv1形状の60%スケールを初期形状とする。底穴半径約4.69mmに対して茎半径1mm、試験位置ずれ2mmを仮定。位置ずれ5mmは成功対象から外し、中止の対照条件にした。薄肉化とヒンジ縮小の造形性は未検証。

## 座標とOnshapeへの移行

CADの原点は閉じた球の中心。Zが上向き。球殻0のヒンジ中心は約(X,Y,Z)=(12.679,0,27.189) mm、軸はY方向。他の5枚はZ周りに60°ずつ回転させた位置となる。

MuJoCoでは球の中心初期位置を世界座標(0,0,0.18)mとし、X方向に0.2m、Z方向に0.07m移動させる。球殻0は-Y軸周りの正回転で開く。切断点は(0,0,0.147)m、短い新芽の基準点は(0,0,0.16)m。若葉2枚より下の細い茎だけを解除し、親枝の拘束は変更しない。

`step/cage_assembly.step` は組立位置を持つCAD交換データ。Onshapeに取り込んだ後、ベースを固定し、球殻ごとに接線方向のヒンジ軸で回転Mateを作る。STEPから設計履歴やMateは復元されない。

将来の `onshape-to-robot` 変換でも、球殻を1個の凸メッシュとして当たり判定に使わない。見た目のメッシュと、内部が空いた分割衝突形状を別に扱う。

## 動作と疑似切断

1. 開いた球殻の中央に既知位置の模擬新芽を配置する（自動認識・接近は未実装）。
2. 6枚を閉じる。
3. 下側の2つの鈍いブロックを中央へ動かし、位置条件が成立したら茎の固定拘束を解除する。
4. 自由になった対象を接触だけで保持し、上昇・横移動させる。
5. 箱の上で元の高さへ下降し、2秒かけて開いて重力で排出する。全体は10秒。

切断ブロックは位置とタイミングを示す代用形状で、刃ではない。保持台、ガイド、取付、刃の干渉、安全カバーは未設計。生の茎を切る手順や切断能力は、この計算から判断できない。

残す植物と球殻・切断代用ブロックの接触を監視し、切断前の接触で動作を中止する。対象位置・切断点は既知であり、画像から新芽と古葉を判別する機能はない。残す植物は固定剛体なので、無接触判定を超えて植物損傷を予測できない。

## 未設計・未検証

- 1モーターで6枚を閉じるリング／ワイヤー／リンク機構と、球殻の同期誤差
- サーボの寸法、取付、トルク、角度範囲、実際の重量
- 切断ユニットの固定方法と球殻開閉時の通過空間
- 葉の柔軟性、茎の破断、植物への損傷、噛み込み、排出時の付着
- 水濡れ・清掃、繰返し寿命、印刷公差、支持材除去、ヒンジの摩擦
- 新芽の位置・姿勢を画像から推定するAIとカメラ校正

最初の印刷では球殻1枚とヒンジ取付部の嵌合・開閉範囲を確認する。全部品を印刷する前に支持材・造形姿勢をスライサーで確認する。
